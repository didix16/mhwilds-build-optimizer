Wilds Forge — unofficial Monster Hunter Wilds build optimizer.
Monster Hunter and game names, text, icons and other game assets are owned by CAPCOM.

Equipment, skills, descriptions, crafting materials and English/Spanish game localization:
MHDB Wilds — https://docs.wilds.mhdb.io/
Data importer reference — https://github.com/LartTyler/mhdb-wilds-data
Snapshot metadata and SHA-256 checksums: data/manifest.json.
The extraction toolkit's GPL-3.0 license is not represented as a license to CAPCOM's game assets.
