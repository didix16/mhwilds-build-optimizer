WILDS FORGE — STATIC BUILD

Serve this directory using an HTTP static file server. No backend is required.
Do not open index.html directly with file:// because the browser blocks module Workers.
On HTTPS or localhost, the application caches its data and assets after the first visit.

Use the Data & sources tab for dataset dates, game version, attribution and known limits.
Damage is an estimate per configured combo, not DPS. Results are best-found and do not
certify global optimality. Every emitted build is independently checked for required skills.
